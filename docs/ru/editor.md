# Редактор `doc-editor`

Файл: `doc_editor.py` (устанавливается как команда `doc-editor`).

Интерактивный vim-подобный редактор `.docx` с курсором
на текущем блоке.

## Запуск

```bash
doc-editor example.docx
```

Если файла нет — редактор создаст его при сохранении.

## Концепция

- Есть **курсор** — индекс текущего блока (0-based, показывается
  как `[N/total]` в приглашении).
- Большинство команд работают с **текущим блоком**, а не с номером.
- Приглашение: `[3/7]> ` — блок 3 из 7.

## Команды

### Основные

| Команда | Псевдоним | Что делает |
|---|---|---|
| `format` | `f` | задать параметры текущего блока; если блоков нет — создаёт первый |
| `edit` | `e` | изменить содержимое текущего блока (многострочно) |
| `delete` | `d` | удалить текущий блок (с подтверждением) |
| `append` | `a` | создать новый блок **после** текущего и перейти на него |
| `prepend` | | создать новый блок **перед** текущим и перейти на него |

### Навигация

| Команда | Псевдоним | Что делает |
|---|---|---|
| `moveto N` | `m N` | перейти к N-му блоку |
| `move M` | `mv M` | переместить текущий блок на позицию M |
| `swap M` | `sw M` | поменять текущий блок и M местами |
| `start` | `home` | в начало документа |
| `end` | | в конец документа |
| `next` | `n` | к следующему блоку |
| `prev` | | к предыдущему блоку |

### Просмотр

| Команда | Псевдоним | Что делает |
|---|---|---|
| `list` | `l` | краткий список (текущий помечен `>`) |
| `show` | `s` | подробно показать текущий блок |
| `raw` | `p` | вывести все блоки в исходном виде |

### Файл и выход

| Команда | Псевдоним | Что делает |
|---|---|---|
| `save` | `w` | сохранить `.docx` (создаёт файл/каталоги) |
| `reload` | | перечитать файл |
| `quit` | `q` | выход (спросит про несохранённые) |
| `wq` | | сохранить и выйти |

### Встроенные в `cmd.Cmd`

| Команда | Что делает |
|---|---|
| `help` / `?` | список команд |
| `help <команда>` | справка по команде |
| `Ctrl-D` | как `quit` |
| `Ctrl-C` | мягкий выход |

## Многострочный ввод

`edit`, `replace`, `insert`, `append` используют многострочный
ввод. Завершение — строка, состоящая из одной точки:

    > Это первая строка
    > Вторая с {text format:"..."}выделением{/text}
    > .
    Блок обновлён.

## Пример сессии

```
$ doc-editor example.docx
Загружено: example.docx — блоков: 2

[1/2]> list
>  1 [h:1]    Заголовок первого уровня
   2          Абзац с текстом

[1/2]> edit
Текущее содержимое блока 1:
Заголовок первого уровня
Введите текст. Строка '.' — конец ввода.
> Новый заголовок
> .
Содержимое блока 1 обновлено.

[1/2]> append
Создан блок 2 (курсор на нём).

[2/2]> edit
...
> Абзац с {text format:"text-style(bold)"}жирным{/text}
> .

[2/2]> moveto 1
--- Блок 1 ---
Параметры: type:"h:1"
Содержимое: Новый заголовок
--- конец ---

[1/2]> move 2
Блок перемещён на позицию 2.
--- Блок 2 ---
...

[2/2]> start
--- Блок 1 ---
...

[1/2]> wq
Сохранено: example.docx — блоков: 2
```

## Поведение `move` и `swap`

- `move M` — используется «конечная позиция» (как `:move` в vim).
  Курсор остаётся на перемещённом блоке, но уже под новым номером.
- `swap M` — курсор остаётся на том же логическом блоке, который
  теперь находится на позиции `M`.

## История команд

Сохраняется через модуль `readline` (Linux/macOS — из коробки).
На Windows можно поставить `pyreadline3`, но редактор работает
и без неё.

## Ограничения

- Встроенные теги `{text}` / `{image}` — часть содержимого
  блока, отдельных команд для них нет.
- Таблицы редактируются как обычные блоки (`{block type:"table"}...`)
  без специальных команд.
- Файл при `save` перезаписывается целиком.
